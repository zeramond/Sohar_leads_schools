# Sohar Leads CRM

## Overview
Personal CRM for Saleh to manage ~1,714 business leads in Sohar, Oman. Import from Excel, search/view leads, send WhatsApp outreach with auto status tracking.

## Tech
- Prisma ORM with `SoharLead` model (table: `sohar_leads`)
- Raw SQL not used — all queries via Prisma
- `xlsx` library for Excel parsing
- No auth required (personal tool)

## Design — "Zeramond" Dark Aesthetic
- Dark forced: `defaultTheme="dark"`, `enableSystem={false}`, `className="dark"` on html
- Color tokens: pink-500 primary (`330 81% 60%`), zinc-950 background, zinc-900 cards
- Amber badges for Pending, emerald badges for Contacted
- Pink accent buttons (WhatsApp, Import)
- hero-gradient utility for subtle pink radial gradient background

## Key Architecture
- `app/page.tsx` — Server component fetching initial stats, delegates to `DashboardClient`
- `components/dashboard-client.tsx` — Client component: search, leads table, WhatsApp, stats
- `components/import-modal.tsx` — Client component: file upload dialog
- API routes: `/api/leads` (GET), `/api/leads/[id]/contact` (POST), `/api/import` (POST)

## Phone Normalization
Strip spaces/dashes/parens, handle +968/00968/968/0 prefixes, 8-digit → prepend 968.

Business→companyName, Category→category, Phone→phone, Website→website
